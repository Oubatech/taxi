# מלך המוניות — אתר תדמית

אתר סטטי (ללא שרת) לשירותי מונית לשדה התעופה מחיפה והצפון. בנוי עם Next.js + React + TypeScript + Tailwind CSS, ומיוצא כקבצים סטטיים בלבד (`output: export`) — אין צורך בשרת רץ, ניתן לארח בכל אחסון סטטי.

## הרצה מקומית

```bash
npm install
npm run dev       # פיתוח - http://localhost:3000
npm run build     # בילד סטטי לתיקיית out/
```

לאחר `npm run build`, כל האתר (HTML/CSS/JS סטטיים) נמצא בתיקיית `out/` ומוכן להעלאה לכל אחסון.

## מבנה

- `app/` — עמוד הבית, layout, מטא-דאטה, sitemap.xml, robots.txt, תמונת שיתוף (OG image) שנוצרת אוטומטית.
- `components/` — כל חלקי הדף (Header, Hero, שירותים, אזורי שירות, שאלות נפוצות, יצירת קשר וכו').
- `lib/site-config.ts` — **כל פרטי העסק במקום אחד** (שם, טלפון, ווטסאפ, אזורי שירות, מספר נוסעים מקסימלי).

## דברים שחובה לעדכן לפני עלייה לאוויר

1. **דומיין אמיתי** — ב־`lib/site-config.ts`, עדכנו את `siteUrl` מ־`https://example.co.il` לכתובת האתר האמיתית שלכם (זה משפיע על sitemap, קישורים קנוניים ותגי שיתוף).
2. **לוגו ותמונות אמיתיות** — כרגע האתר משתמש באייקונים גנריים (🚕) כי לא היו זמינות תמונות אמיתיות של הרכב/העסק. מומלץ להחליף בתמונות אמיתיות — זה משפר גם אמון וגם SEO.
3. **חוות דעת לקוחות אמיתיות** — במכוון לא הוספתי חוות דעת מומצאות. ברגע שיש לכם ביקורות אמיתיות (למשל מגוגל), אפשר להוסיף אותן כסקשן נוסף.

## SEO — מה כבר בנוי בתוך האתר

- **HTML סטטי מוכן מראש** (לא צריך JS כדי לראות תוכן) — הכי טוב למהירות ולדירוג בגוגל.
- תגיות מטא מלאות: כותרת, תיאור, מילות מפתח בעברית, Open Graph לשיתוף ברשתות.
- **Structured Data (JSON-LD)**: סכמת `TaxiService` עם אזורי שירות, וסכמת `FAQPage` תואמת לשאלות הנפוצות בעמוד — זה מה שמאפשר לגוגל להציג "תשובות נפתחות" ישירות בתוצאות החיפוש.
- `sitemap.xml` ו־`robots.txt` נוצרים אוטומטית בבילד.
- כתובת אחת נקייה (URL קנוני), RTL מלא, מותאם מובייל.

### הצעד הכי חשוב שהאתר לבדו לא יכול לתת: Google Business Profile

עבור עסק מוניות מקומי, רוב החיפושים הרלוונטיים ("מונית לשדה התעופה בחיפה" וכו') מוצגים בגוגל דרך ה"מפה המקומית" (Local Pack / Google Maps), **לא** רק דרך תוצאות האתר הרגילות. כדי "להיות ראשונים בגוגל" באמת:

1. פתחו **Google Business Profile** (עסק בגוגל) בחינם, עם אותו שם עסק, טלפון וקטגוריה ("שירות מוניות").
2. ודאו התאמה מלאה בין הפרטים באתר (השם/הטלפון כאן) לבין הפרטים בפרופיל העסקי בגוגל — חוסר התאמה פוגע בדירוג.
3. בקשו מלקוחות מרוצים חוות דעת אמיתיות בגוגל — זה משפיע מאוד על הדירוג המקומי.
4. הגישו את כתובת ה-sitemap (`/sitemap.xml`) ל-**Google Search Console** אחרי העלייה לאוויר.

## פרסום ממומן בגוגל (Google Ads)

לא הקמתי חשבון Google Ads — זה דורש חשבון בתשלום שרק אתם יכולים לפתוח ולנהל. האתר כן **מוכן טכנית** לשמש כיעד לקמפיין:
- כפתורי "התקשרו" ו-"ווטסאפ" בולטים בכל מסך (כולל פס תחתון קבוע במובייל) — מתאים לשימוש כ"הרחבת שיחה" (Call Extension) בגוגל אדס.
- דף מהיר וממוקד המרה — תנאי בסיס טוב לציון איכות (Quality Score) גבוה בקמפיין.

כשתהיו מוכנים, אפשר לפתוח חשבון ב-ads.google.com ולהפנות את המודעות לכתובת האתר.

## המלצת אחסון (הרצה בפועל)

האתר סטטי לגמרי, אז כל אחסון סטטי מתאים. הכי פשוט:

- **Vercel** (מומלץ) — מזהה Next.js אוטומטית, כולל דומיין חינמי לבדיקות, HTTPS אוטומטי. פשוט מחברים את ה-repo.
- **Netlify** — גם עובד מצוין לאתר סטטי; יש להגדיר build command `npm run build` ו-publish directory `out`.

לאחר מכן ניתן לחבר דומיין ישראלי (`.co.il` או `.il`) דרך ניהול הדומיינים של האחסון שנבחר.

## החלטות עיצוב שנעשו כברירת מחדל

- **פלטת צבעים**: צהוב מונית / שחור / לבן — קלאסי ואמין לשירות מוניות. ניתן לשנות בקלות ב-`app/globals.css` (המשתנים `--brand-yellow`, `--brand-black`).
- **ללא הצגת מחירים** — האתר מפנה ל"צרו קשר להצעת מחיר" במקום תעריף קבוע. אם תרצו להציג תעריף קבוע לנתב"ג, אפשר להוסיף בקלות סקשן מחירים.
